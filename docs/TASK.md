# Промпт для Claude Code: Telegram-бот AI Report Bot

Ты — senior Python-разработчик. Создай готовый к запуску Telegram-бот **AI Report Bot** на основе учебного кейса по AI-автоматизации.

## Цель проекта

Telegram-бот с двумя режимами:

### 1. AI Client Report

- Пользователь отправляет боту транскрибацию диалога с клиентом.
- Бот отправляет текст в Anthropic Claude Haiku 5.5 и получает строго валидный JSON со следующими полями:
  - `client_name`
  - `topic`
  - `main_request`
  - `mood`
  - `next_steps`
- JSON сохраняется в папку `data/json/` с уникальным именем файла.
- Данные подставляются в HTML-шаблон через Jinja2.
- Из HTML генерируется PDF через WeasyPrint.
- PDF сохраняется в папку `reports/`.
- Бот отправляет пользователю PDF-файл и краткую сводку извлечённых данных.

### 2. Product Card Generator

- Пользователь отправляет боту URL товара.
- Бот пытается получить со страницы:
  - название товара;
  - краткое описание;
  - цену;
  - основные характеристики, если доступны;
  - ссылку на главное фото товара.
- Полученные данные передаются в Claude Haiku 5.5, который формирует структурированный JSON:
  - `product_name`
  - `short_description`
  - `price`
  - `currency`
  - `key_features` — список строк
  - `image_url`
  - `source_url`
- Данные подставляются в HTML-шаблон карточки товара.
- Из HTML генерируется PDF через WeasyPrint и отправляется пользователю в Telegram.

## Обязательный fallback при блокировке scraping

Если сайт блокирует запрос, возвращает капчу, требует JavaScript, отдаёт ошибку `403`, `429` или структура страницы не распознана, бот **не должен падать**.

Вместо этого бот должен:

1. Сообщить пользователю, что не удалось автоматически извлечь данные с сайта.
2. Предложить ручной режим.
3. Последовательно запросить у пользователя:
   - название товара;
   - краткое описание;
   - цену и валюту;
   - ключевые характеристики — по одной строке или списком;
   - прямую ссылку на фото товара, если она есть.
4. После получения данных передать их в Claude Haiku 5.5 для нормализации в JSON.
5. Сгенерировать PDF по тому же шаблону и отправить его пользователю.

Если пользователь не даёт ссылку на фото, PDF должен создаваться без изображения, с аккуратным placeholder-блоком.

## Требуемый стек

Используй именно этот стек:

- Python 3.11+
- `python-telegram-bot` для Telegram-бота
- Anthropic Python SDK для вызова Claude
- Jinja2 для HTML-шаблонов
- WeasyPrint для генерации PDF
- Pydantic для валидации JSON-ответов LLM
- `requests` и `BeautifulSoup4` для базового scraping
- `python-dotenv` для переменных окружения
- `logging` для логирования
- `pytest` для базовых тестов

Не используй базы данных, Docker, Celery, Redis и веб-фреймворки. Это должен быть простой локальный MVP.

## Модель Anthropic

**Важно:** используй модель **Claude Haiku 5.5**.

- Используй Anthropic Messages API.
- Модель по умолчанию: `claude-haiku-5-5`.
- Название модели вынеси в `.env`:

```env
ANTHROPIC_MODEL=claude-haiku-5-5
```

- API-ключ хранится в `.env`:

```env
ANTHROPIC_API_KEY=
```

- Токен Telegram-бота хранится в `.env`:

```env
TELEGRAM_BOT_TOKEN=
```

- Запрос к Claude должен требовать ответ **только в формате JSON**, без Markdown, пояснений и лишнего текста.
- Ответ модели валидируй через Pydantic.
- Если JSON невалиден, сделай до 2 повторных попыток с уточняющим системным сообщением.
- Если после повторов JSON всё равно невалиден, отправь пользователю понятное сообщение об ошибке и запиши detail в лог.

## Логика Telegram-бота

Реализуй понятный сценарий через команды и состояния:

- `/start` — приветствие и краткое описание возможностей.
- `/report` — режим отчёта по диалогу.
- `/product` — режим карточки товара.
- `/cancel` — отмена текущего сценария.
- `/help` — список команд.

### Сценарий `/report`

1. Бот просит прислать текст диалога.
2. После получения текста показывает статус: «Анализирую диалог…».
3. Вызывает Claude Haiku 5.5.
4. Генерирует PDF.
5. Отправляет PDF и краткое резюме.

### Сценарий `/product`

1. Бот просит прислать URL товара.
2. Пытается выполнить scraping.
3. Если scraping успешен, вызывает Claude и генерирует PDF.
4. Если scraping заблокирован или данные неполные, запускает ручной fallback.
5. После завершения отправляет PDF.

Используй `ConversationHandler` из `python-telegram-bot` для управления состояниями пользователя.

## Требования к PDF

- PDF должен выглядеть как профессиональный бизнес-документ.
- Для отчёта по диалогу используй заголовок «Отчёт по клиентской консультации», дату генерации, имя клиента, тему, основной запрос, настроение и следующие шаги.
- Для карточки товара используй заголовок «Карточка товара», фото, название, цену, краткое описание, список ключевых характеристик и ссылку на источник.
- Добавь футер: «Сгенерировано AI Report Bot» и дату.
- Шаблоны должны быть адаптированы под печать A4.
- Если изображение недоступно, PDF должен корректно создаваться без фото.
